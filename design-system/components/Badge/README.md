# Badge

A short word that tags a state or a kind. The consumer gives the word (children) and `tone`.

- `walle` (rust): over budget, to trim, Real problem. `eve` (blue): measured, selected. `leaf` (lean): kept, done. `trim`: highlight. `neutral`: anything else.
- Color never carries the meaning alone. `walle` and `leaf` are close in lightness, so the word does the work.
- Numbers inside a badge stay as they are; do not wrap them in `code`.
