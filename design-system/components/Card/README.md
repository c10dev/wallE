# Card

A `surface` box that groups one result or one block of facts. The consumer gives the children, and optionally `as` (`div`, `section` or `article`) and other HTML attributes such as `aria-label`.

- One `line` border, `radius-lg`, `space-4` padding. The children stack with `space-3` between them.
- No shadow: a card is fixed to the screen.
- Put the most important fact first, for example a verdict `Badge` and a number.
- Use `section` with `aria-label` when the card is a region of the screen.
